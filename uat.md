_Created: 2026-06-01_

## Project Info
- **Stack**: Static site generated by Python (`site/build.py`) from markdown sources. No runtime, no JS framework. Ships zero external JS (inline JSON-LD + one inline `onclick` for the mobile menu), no web fonts, no images, no third-party requests.
- **Build**: `python3 site/build.py` → writes `dist/` (gitignored; CI rebuilds on push to `main`).
- **Validate**: `python3 site/validate.py` (9 structural checks) → `python3 -m pytest tests/` (86 checks).
- **Preview**: serve `dist/` locally, e.g. `python3 -m http.server 8848 --directory dist`. (A Claude Preview `.claude/launch.json` config `dist-preview` exists for browser automation.)
- **Deploy**: GitHub Actions `deploy-site.yml` runs build → validate → pytest → GitHub Pages on every push to `main`. Any failure blocks the deploy.
- **Key pages**: `index.html` (home/README), `alerts.html` (the feed), `advisories/` (one file per incident + index), `playbooks/`, `prevention/`, `sources/`, `tools/`, plus `contributing/security/changelog/backlog/issues`.
- **LLM/data artifacts**: `llms.txt`, `llms-full.txt`, `llms-ctx.txt`, per-section `llms.txt`, `advisories.json`, `advisory-schema.json`, `search.json`, `feed.xml`, `sitemap.xml`, `robots.txt`, `api/v1/*.json`, `.well-known/security.txt`.

## Critical Flows (run every time)
1. **Build is clean**: `python3 site/build.py` → `validate.py` (9/9) → `pytest` (all pass). No failures = deployable.
2. **Home renders**: title, "View raw markdown"/"Edit on GitHub" actions, intro, **"Last full sweep" date is current** (matches ALERTS.md "Last refreshed"), nav + sidebar (≥900px) + TOC (≥1200px).
3. **Alerts feed**: `alerts.html` shows newest-on-top entries, each linking to a full advisory; "Last refreshed" date present and < 7 days old.
4. **Advisory page**: meta bar shows severity/status badges + Disclosed/Updated dates + ecosystem/tool/tag chips; TOC + breadcrumb present.
5. **Responsive**: 375px mobile single-column; hamburger toggles the full-section nav (`body.nav-open`). Dark mode themes the whole page.
6. **No broken links / no 404s**: `validate.py` "All internal links resolve" passes; live sweep of artifact URLs returns 200.
7. **llms.txt correct**: starts with `# title` + `> summary`, has Active alerts/Advisories/Playbooks/Prevention/Optional sections, lists every advisory, size annotations are accurate (now dynamic).

## Known Stable Areas
- Build pipeline + validators + pytest (deterministic; 86 checks).
- Page weight / performance (HTML+CSS only, 2 requests/page).
- Internal link integrity (enforced by `validate.py` + tests).

## Known Flaky / Unstable Areas
- **`llms-full.txt` size vs cap**: grows ~daily with the corpus. Watch `LLMS_FULL_MAX_BYTES` (640KB) and `LLMS_CTX_MAX_BYTES` (96KB) in `tests/test_llms.py`. Long-term, trim `historical`-status advisories from `llms-full.txt` rather than raising the cap indefinitely (it stops being a "one paste" file past ~200K tokens).
- **Date freshness**: README "Last full sweep" and ALERTS.md "Last refreshed" are hand-maintained per sweep — verify they match the latest `runs.log.md` entry each run. Relative phrases ("two days ago") rot — prefer absolute dates.
